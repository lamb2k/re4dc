# Owner rule 2026-11-19 ("Split it"): no original service code in the engine image. Original code is allowed only
# for behaviour: decisions, scripts, player, partner and enemy logic, and the behaviour generator. Everything under
# it (skeleton and pose, collision and actor volumes, routes, models and parts, cameras and frustum, input, math,
# allocation, drawing, actor and object tables) is the engine's.

# entry here. Default deny: a unit not listed is service code, whole.
#
# Format: "## <group>: <reason>", then "<unit> <pattern>..." (fnmatch on the demangled or the mangled name);
# "!<unit> <pattern>..." takes a function out of an allowed unit (service code inside a behaviour unit, split at
# function boundaries as the E1 audit asks). Exceptions win over every allowing line.
