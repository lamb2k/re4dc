I-013 requires full geometry only where the boss actually draws live: grabs, live QTEs and short in-engine scenes. A story event presented by a PS2 movie needs no special boss render model or still. This audit reads the original BIO4MOV catalogue and pins current room/actor source; it changes no model selection, event handler, runtime or recipe. Settled choices stay unchanged.

## Original disc and qualification boundary

The original USA PS2 ISO contains BIO4MOV.AFS at byte2451812352, size1963034624, with287 named entries. Its original directory/name records were retained and independently replayed exactly. All25 distinct EVD names referenced by the14 audited boss-room sources have a same-named original SFD. Original EVDs and directory facts are private; no movie payload was copied, transcoded or published. Per-entry offsets/sizes and first2048-byte fingerprints are retained, **not claimed as full SFD hashes**.

A catalogue member proves an authored movie exists. It does **not** prove the current recipe enables the hook, the movie is staged/resident, playback passes, callbacks/skip/QTE outcomes remain equivalent, or a differently named source scene is the same clip. RouteMoviePlay's missing-media fallback may execute the original source EVD, so do not count a fallback as accepted movie coverage. This is a bounded source/catalogue audit, not an exhaustive dynamic event or whole-fight gate.

**Movie-backed QTE is not automatically a live boss QTE.** Existing RouteMoviePlayQte sets Disp_flg to hide the world and leaves only movie/UI while source callbacks advance. Conversely, `SceEventStart`, a special camera or an actor's `beginEvent` does not by itself mean an EVD/movie. Catalogue absence is bounded to exact room prefixes and this original disc, not proof that no other clip could be reused; any claimed reuse needs explicit source binding.

For new levels, retain one full source parent for actual live moments; no additional story-cutscene render variant/sheet. Preserve source state/collision/attachments/motion and callback/skip semantics. Verify actual full switching in live grabs and short scenes with current slots2 and shipping data; no acceptance is inferred from full bytes on disk or a movie catalogue match. Story movies themselves remain room-owner staging/route gates, not new boss18 runtime work.
