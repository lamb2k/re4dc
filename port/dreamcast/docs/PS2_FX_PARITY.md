| Reason | Records |
|---|---|

| PS2 has N record(s) within 100 mm (replaced, not deleted) | 484 |

| selector shared with a kept record | 140 |
| PS2 keeps Esp48 sheets with this texture | 8 |

Changed records (matched, a render field differs) are not restyled by PS2_FX_GEN: a generic restyle of colour / size / fades would rewrite effect state, so only the hand rows (camera haze kPs2Haze, r104 statics) do it. Added PS2 records are never drawn (user decision: no wholesale PS2 EFF); the one hand-qualified addition is PS2_FX_ADDITIONS (r118 area 6, r11c haze).

## Water (lane water16, WATER_PS2, default 0; docs/lanes/water16.md)

The PS2 cut the generator water: `Espgen42_Trans` is `jr ra` and `Espgen45_Trans` only clears a flag, so neither draws.
Its rooms draw the water as stacked Esp08 world planes instead (dark base 0xf7, two scrolling 0xf2 layers, an animated
0xfe / 0xef noise layer). WATER_PS2 draws those planes render-side, a second hand-qualified PS2 addition: 24 rows in
r107 r108 r10a r10b r11a r11b (`src/game/water_ps2_table.inc`, generated by `tools/d367/water/water_ps2_table.py`); no
PS2 record is spawned. r102's GameCube water (espgen45, Esp4c / Esp4d ripples) has no PS2 counterpart and stays undrawn.
The GameCube mirror puddles (r103 / r105: mask-stage Esp00 0xfc + frame copy) have no PS2 counterpart either (the PS2
uses plain Esp08 / Esp00 planes, no mirror): not drawn, matching the PS2.
