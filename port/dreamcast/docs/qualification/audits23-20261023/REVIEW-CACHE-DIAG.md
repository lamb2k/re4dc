## Findings closed before this verdict

1. **Initial P1/P2 coherence, substantive:** Original6a can take the first P2 counter snapshot before any whole helper has run. Pinned KOS init.c enables cache before zeroing BSS through P1; a dirty cached zero can therefore coexist with stale physical RAM. Post-sweep observer stores protect later helper increments, but do not authenticate that first snapshot. Repair59 adds a one-time 64-byte writeback of the two isolated counter cache lines inside the first safe snapshot's IRQ lock, before its first P2 read. The pinned small-range implementation is two OCBWB operations, below the65560-byte whole-helper threshold. It does not invalidate/reset prior real P2 counts: a preceding helper already cleaned the old P1 alias. Separate cold dirty-P1/stale-P2 and warm clean-P1/prior-count controls pass; removing the first writeback fails the cold control.
2. **Diagnostic knob parser:** The previous Make filter accepted list/wildcard values such as `0 1` and `%` and silently treated them as OFF. Final5e replaces it with exact0/1 comparisons and tests list/wildcard/empty rejection. Explicit0/1 behavior and runtime/UI source are unchanged by this final delta.
