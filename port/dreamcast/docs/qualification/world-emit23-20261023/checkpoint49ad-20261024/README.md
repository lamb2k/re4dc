# World Emit sealed helper preservation (49ad)

This checkpoint preserves 89 selected C-side authored helper, document and report files byte for byte, based on public source `49ad20f9932d638ddb7becf5db6f86b92e0a76a2`. It is an archive, not a new build, test result, runtime integration or acceptance decision. The original absolute machine paths in the archived helpers remain unchanged. Do not run archived build, stage, guest or launch scripts merely to verify preservation.

`manifest.json` lists every copied file, its original path, exact size/SHA-256 and classification. Prior seals are checked where available. A scoped `.gitattributes` disables text conversion for the archived originals, preserving CRLF and legacy document encodings in Git blobs as well as the working tree. The four private fixture bodies are omitted; only their identity metadata is retained. Live STATUS/INBOX, raw logs, binaries, images, extracted game assets/geometry/AEV, generated bytecode, copied allocator-excerpt outputs and active unsealed successors are excluded. Symbol/DWARF JSON records are ABI/type metadata, not game asset payloads. Authored tests may extract snippets from already tracked public port source at execution time; extracted output is not committed here.
