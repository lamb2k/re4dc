# Full partner Ashley PS2 rig

This unit contains only the default-off `ASHLEY_PS2_RIG` adapter for partner
Ashley, model3 over 141 source joints and seven adopted source roles.
It requires `PS2_ASHLEY=2` and a private `ASHLEY_PS2_RIG_DIR` generated by
`rig_header.py` from the three full hand conversions. Playable pl01/model0
keeps its separate typed owner and adapter.

`tools/ps2_ashley.py convert OUT --rig --hands 0|1|3` retains original PS2
geometry, normals, UVs, textures and authored skin weights. Every influence
survives through the reviewed garment map; folding and truncation are refused.
All three states retain their full geometry. The normal state has4925
triangles and45draw slots. Source contracts still cover all141 parents and
inverse binds, every adopted source BIN/TPL role, current pointers, revision,
finite matrices and the existing lifetime/material leases.

PS2 shared bones use the package's original PS2 bind. Hair/skirt links use the
existing game solver's skin delta and runtime inverse bind. No extra cloth
solver, animation tick, gameplay RNG, collision or event change is added.
The existing neutral PS2 face exception remains; new expressions are not claimed.

Registry generation accepts `--ashley-rig --slots` to require the full original
pl11 rig contract. Both explicit rig mode and implicit `ps2_rig` metadata reject
`--source-normal-length`: newly drawn normals use only PS2 directions and
magnitudes. Legacy non-rig conversion is unchanged. No game assets enter Git.

Use the existing private native/PS2-atlas-mask pipeline, then generate a v1
package with `--pack-bones 96 --slots --wide-identity --pool --ch23-facts
--ashley-rig`. There is no Ashley-specific role-width, storage, package alias
or LOD exception. `full_rig_gate.py` runs the actual unchanged target validator,
malformed packages and optional combined room packages under the exact current
play identity flags. The r202 test uses its pre-existing wide Castle profile.

This clean unit intentionally omits the rejected distance LOD experiment.
Its preserved branch/evidence remains separate:7%/14% fewer triangles at a
17,440-byte static cost was rejected. No new LOD optimization is implied.

The previously linked full adapter cost224bytes of static memory, independent
of the rejected LOD. Source/host, linked SDK identities and live runtime gates
remain distinct. Appearance/interaction review, STRICT gameplay, live memory,
MODELLED timing and physical console acceptance are required before adoption.
Cache-model runs await the coordinator's fixed binary/control; this unit does
not patch the emulator, production recipe, SD stage or release.
