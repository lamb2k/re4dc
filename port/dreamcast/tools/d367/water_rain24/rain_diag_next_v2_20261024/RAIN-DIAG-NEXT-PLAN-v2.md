## Publication/cache/lifetime protocol

Single writer is the existing synchronous source/main thread: no IRQ hook or timer callback; do not leave seq odd across the setter call, renderer call, logging, allocation, SceSleep or scheduler boundary. Each event opens a bounded scalar publication, clears NATIVE_SAMPLE_VALID for every non-return event, updates values/counters, uses compiler memory barriers before payload and final even seq, then closes. Never nest publications. ABI must equal1 exactly; initialized ABI0 is never accepted. A malformed/reentrant publication latches invalid and leaves a rejectable receipt without changing rain execution.

Reserve final even seq0xfffffffe for terminal invalid/exhausted publication only. The last normal even is0xfffffffc. From0xfffffffc use odd0xfffffffd, publish the exhaustion fault, close even0xfffffffe and stop all further diagnostic writes. Never publish odd0xffffffff, wrap to0 or leave exhaustion odd. Readers reject seq>=0xfffffffe even if a malformed producer omitted the fault bit. Any generation/u16 counter/u32 aggregate reaching its maximum similarly latches exhaustion without wrap; no reset erases incompleteness. Diagnostic exhaustion changes no rain execution. Observer reads seq ->128B ->seq through the same exact-owned RAM handle; all three seq copies must equal a normal even, abi_flags must equal1 exactly, otherwise bounded retry then UNKNOWN. Stable memory is not completed-image/present identity.

Native sample validity is an explicit separate contract. Before production queue fields are cleared, capture their frame/room locally; the actual ticket is still consumed normally. Keep that captured key in diagnostic queue_frame/rooms.high16 with QUEUE_KEY_VALID through the return event, while actual-pending flag is0. Require callback_generation==setter_generation!=0, all callback/queue/event frames equal actual pG->Frame_cnt, both rooms equal actual current0x10c and ABI/current generation nonexhausted. After actual return recheck the nonwrapping sequence witness, which binds all published identity/state fields, and recheck the explicit generation/frame/room joins against the captured scalar key; a changed publication sequence rejects even a same-frame replacement callback with otherwise identical keys. Publish native_requested and actual returned value, RETURN event and NATIVE_SAMPLE_VALID only when this exact join survives. On mismatch publish invalid sample context, never an old return joined to a new cause; lifetime actual-return counters may still advance without controller attribution.

Every setter, RoomInit, new/replaced callback/ticket and any unrelated event publication clears NATIVE_SAMPLE_VALID before changing interpreted fields; simplest rule is all non-return publications clear it. New cause/callback/cancel also clears stale queue context. Zero API return with a valid joined call is distinct from no observed call.
