Catalog absence remains Unknown; neither FCV/BIN/EVD tags nor file names imply PS2. Complete successful MRAM reads supply bounds; MRAM+ARAM lengths must never be hashed as one allocation. Duplicate current captures never hash relocated bytes. Distinct overlapping owners, changed live extents, stale catalog tokens, serial exhaustion and external-key FCV prefixes fail closed. Source retirement flushes prior accepted identities before backing destruction.

Evaluated-only and zero-record paths produce no use.
