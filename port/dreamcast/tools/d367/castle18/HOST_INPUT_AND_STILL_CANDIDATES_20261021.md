# Original J host-input and still candidates

These are private host tools for the existing immutable J program and image. They do not modify the game, assets, difficulty, health, AI, hitboxes, source flags or timers. Neither candidate has a live qualification yet. J222 stopped before guest launch because the exact image is unavailable.

`capture_original_j_rgb565_fast.py` preserves the existing D221 eight-MiB VRAM read, logged framebuffer pointers, 32-bit bank mapping and RGB565 conversion. It replaces scalar host pixel decoding with NumPy operations. Three deterministic synthetic checks, including a four-MiB bank crossing, match the old decoder exactly; the compatibility receipt records both file hashes. This narrow decoder compatibility check is not an exact-rendering campaign or game/hardware performance result. Actual sampled source-frame and health intervals must still be retained.

Use this only from the existing owned-guest controller, after exact PID, executable path and start-FILETIME validation. Preload NumPy/Pillow before guest launch with the prepared readiness handshake, then use the original read-only capture interface. Do not add a screenshot-only guest. The candidate has not yet demonstrated shorter live capture intervals: the first planned functional run, J222, never launched. Preserve all earlier PNGs and their asynchronous before/after health context.

`original_j_fixed_pitch_burst_candidate.py` is an unselected normal-controller candidate for the original r201 Garrador. Its explicit saved boss and player HP arguments prevent accidental use of stale health templates. It keeps actual scaled-sphere, original laser and actual damage-part 37 checks, the six-shot bound, injury/phase/held-world guards and the original death callback requirement. Its changes affect ordinary key timing only: it avoids flipping physical pitch direction based on lagged animated weapon matrices, aims 70 source units below the unchanged sphere centre, preserves the actual A cooldown, and avoids blocking screenshots at each intermediate HP acknowledgement. Original `PlWepLockCtrl` and observed m3r input establish the existing forward-key pitch convention; no source input variable is written.
