## Source and evidence boundaries

- `native_ui.cpp::load` returns a live key hit before `texpack::find`. Archive/source-handle invalidation does not imply the keyed upload was evicted. Missing key, package error, metadata pressure, VRAM fragmentation and room retirement are different conditions.
- `eff_sys.cpp::EspDataLoad/EspDataRelease`, `est.cpp::EstSet`, `espgen10.cpp::espgen10_Update`, and `native_effect.cpp` provide the registration/borrow/decode chain. Stopping the original actor is not by itself a proof that every attached controller was destroyed.
- `em10HeadSet` reuses source pointers. em10LostHead also calls SndCall8:7 and core EstSet sequences, then removes eye effects. Weapon release and event completion explicitly delete effects; module unbind/free still requires the caller ownership proof.
- `SndEmDataReadCheck`, `SndBlkInit`, DVD sound-part cases and `SndNextRoomInit` determine source bank reuse/retirement. `re4dc_audio_arq`, `blk_begin_prebuilt`, `AXSetVoiceState` and room arena preparation determine native audio readiness. A source registered flag alone does not prove an audible native bank.
- The dedicated music thread calls `re4dc_disc_meter_music_thread`; `DiscMeterScope` separates its counters from main/re4-task blocked time. Low-level read-call count is not a fresh-seek count. Aggregate reads near an effect do not establish that effect as caller.
