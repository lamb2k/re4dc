# Guarded atlas runtime candidate

LEON_ATLAS_SPLIT defaults to 0. It is an experimental render candidate, with no
production recipe or release change. It requires PS2_LEON=1, ACTOR_PL08=1,
ACTOR_PL08_PACK=1, LEON_LOD=0 and LEON_ATLAS_SPLIT_DIR holding private generated
leon_atlas_split_data.h. runtime_header.py emits that header and the two new
native textures from the sealed square128-v2 candidate; output paths refuse
reuse. Stage the new files under their exact tex key names in a private fixture.
All original texture pack members and source geometry remain unchanged.

The ordinary Leon/pl08/headless owner first builds and validates its complete
existing plan. An atomic adapter replaces only the selected body role's ordered
runs and appends its clamped opaque material. Palette callbacks, current hands,
neck, role infos, source input, weights, existing atlas/hair materials and run
order remain. Cold qualification compares every source/emitted triangle and
exact UV affine mapping, after actual source preflight. Unsupported/changed
source, alternate LOD, charbake atlas key or insufficient run capacity leaves the
ordinary plan unchanged. The flying head does not use this tile and is untouched.

The global immutable table appends 22 IDs after every existing ID: nine for the
standard coat and thirteen shared by pl08/headless body. In the exact retained QA
configuration these are 127..135 and 136..148. The formula also accounts for other
existing registry/hand table sizes; IDs are not hard-coded in runtime admission.
The pl08 package's existing reset first revokes both prepared pl08 proofs, then
resets the thirteen new run proofs along with its existing three source IDs,
before free/republication. The source package generation and full source input
spans are part of cold proof reuse. Standard backing remains compiled const.

Material capability projects a split plan back only if every selected run and
appended material exactly matches a currently prepared binding. It invokes the
unchanged original capability and full material certificate, rather than
claiming a new source shader/material proof. Projection cannot cold-prepare from
a retained plan after reset. Existing actual texture leases, scene pins, source
frame/owner identity and transaction retirement remain mandatory.

pl08 and headless enable arms pass 71/76/77 checks; each includes all 17 original
hand blobs. OFF calls preserve destinations. The headless fixture retains the
