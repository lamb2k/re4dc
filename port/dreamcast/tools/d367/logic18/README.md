# Logic18 host-only current-model attribution

Build an instrumented private copy of `tools/hwmodel/hwsim.c` with `build_profile_sim.py --source ... --out NEW_DIRECTORY`. The source timing model stays unchanged. Generate the exact linked function table with `make_symbols.py ELF symbols.tsv`, then set `L18_SYMBOLS=symbols.tsv` while replaying the complete ordered trace set with the generated `hwsim_profile`. Run `verify_profile.py --original ORIGINAL_PREFIX --profile PROFILE_PREFIX --out validation.json` before using results.

`function_frames.tsv` contains disjoint flat self cost using exact ELF symbol extents; size-zero and uncovered PCs remain unknown. `contexts.tsv` contains observed invocation IDs, parents, self/inclusive fixed-point cycles, owner, completion and invalidation. A complete invocation requires `complete=1` and `invalid=0`. Never add inclusive rows, flat self rows and owner rows together. Owner labels are execution ancestry, not proof of an independent additive subsystem cost. Unknown ancestry remains unknown. Sparse samples begin with unknown roots; they are not full-frame call trees.

SH-4 call/return delay slots remain with the caller/callee respectively. Deferred memory/branch charges retain immutable invocation IDs. Cross-function or unresolved jumps and unconditional same-entry jumps (possible tail recursion) invalidate the current invocation and replace it with an unknown tail frame. Proven callers remain only until an observed return confirms their saved return address; unmatched returns and thread barriers invalidate ancestry. An exact tail target matching an explicit owner entry may label the unknown tail frame, but it is not counted as a complete named-function invocation. Owner3 uses the actual cObjMgr::move entry. Conditional transfers are checked at the observed next PC. IRQs use separate owner 5 contexts; only an exact observed sequential resume restores saved ancestry. This deliberately loses coverage when interrupt return or tail-call identity cannot be established. No guessed nearest symbol ranges or latest-PC owner lookup is used.

`make_runtime_image.py` repairs the simulator input when executed code lives in runtime overlays absent from the stripped main ELF. It requires captured loader base addresses, the exact chosen program directory, matching main .text identity, verified overlay image/relocation hashes, one stable load per module and non-overlapping ranges. It adds relocated overlay PT_LOAD segments without changing the timing model. Run both uninstrumented and instrumented current hwsim on this same augmented ELF for parity. Audit remaining executed PCs outside loaded bytes explicitly; BIOS/trampoline instructions may remain uncovered. Overlay function names require a separately verified symbol map and are not guessed from nearest main-image symbols.

`summarize_profile.py` reports disjoint self, complete named inclusive ranks and owner-root coverage separately. `summarize_pcs.py` reads existing PCS1 records using exact ELF extents and an explicitly selected frame set; it rejects missing frame boundaries or lost records, and labels the result statistical Flycast guest-TMU samples rather than host or console timing.
