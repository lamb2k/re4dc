## Requested bounds concerns resolved

- offline_groups base[c]: adopt first checks every strip index c<l.vertex_count. For indexed meshlets repeat_count is zero, so u==vertex_count and the c<u arm is always taken; base[c] is not dereferenced. For encoded plain repeats, adopt separately enforces q<u and the y/z tags before any group read. The group reader is called only after successful adopt and the SG header/CRC/extent checks. The data borrow is still the loaded package, not an unchecked foreign strip.
- rep>=n: unsigned u=n-rep may wrap at calculation, but no pointer/index uses u before the immediate rep>=n rejection. Vertex count is already1..256 and the repeat count is bounded8-bit. No out-of-range repeat dereference occurs before rejection.
- aliases: plain spans are monotonic/disjoint; same-part indexed-pool intervals cannot overlap an encoded plain span. Across parts, existing part_pool includes BOTH plain and indexed reads and enforces disjoint ascending union ranges, so an indexed pool in one part cannot alias another part's repeat metadata. Indexed-to-indexed sharing inside a part remains supported and never encodes repeat metadata.
- empty SG groups: end==prev consumes no strip and intentionally leaves prev unchanged. Both sg_select and sg_select_lean skip those groups before reading their bbox/span; emit_pick also skips them. Nonempty groups must be monotonic, end on complete strip boundaries, enclose every referenced unique source and finish exactly at strip_bytes. Unused empty-group lo/hi are not consumed.

## Decode, clipping, converter and movie closure

For PREFETCH0, corners refreshes or clears the borrowed decoder at every meshlet. Full paths transform only unique coordinates and copy projected XYZ/outcodes from validated first copies while keeping each repeat's UV/colour. Selected groups authenticate source ranges; fill skips repeats whose source was not primed. Near/far and generic clipping use offline_position for XYZ and retain the original corner UV/colour. Indexed gathers cannot see encoded metadata through an alias. The successor makes the prefetch path obey that same context rule.

The offline converter skips indexed/shared vertex spans, preserves ordered decoded corners including seams, and rewrites SG ranges to include each required first copy. Its validator globally rejects encoded aliases. Exact strip sharing changes only immutable strip-block offsets/physical extent plus CRC/SG binding; it retains each original block byte-for-byte, all vertex bytes and source/LOD records. Fresh-open runtime selects only the explicit alternate after matching the original standard header extent/CRC, validates the alternate body CRC/marker/source extent and adopts the strict reader. Ordinary filenames carrying markers are rejected in mode3.

Movie borrow captures physical mesh/side extents and whole-file CRC/FNV before unpublishing pointers. MeshPackage::close retains the header lineage needed to select ps2-dd3 again. Reload requires the same live room/generation/block/capacity, exact captured file sizes and full captured CRC/FNV for mesh and side; it then re-adopts and rebuilds the sidecar/LUT/gather state. Compact r100's captured physical size and loan capacity are explicitly checked. No old load-time reorder/table pointer is retained in mode3. Source inspection plus current host-binding/H2 evidence support this; this review did not execute KOS I/O.
