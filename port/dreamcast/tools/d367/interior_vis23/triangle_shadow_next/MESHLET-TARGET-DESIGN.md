# Selected-meshlet target design for root review

This is a source/read-only design, not a patch, data schema approval, memory allocation or new proof search. The frozen same-pair pilot stays NO GO at supported camera volumes. User-requested meshlet granularity may avoid whole-cluster bounding-box conservatism on higher-yield targets; it does not repair unknown renderer/raster/source receipts or guarantee useful cuts.

## Exact identity and geometry contract

Use a distinct typed identity `(placement ordinal, placement field, part, cluster, effective nonempty LOD, global meshlet)` authenticated against exact package/policy/IDs and the selected affine. Never use global meshlet alone: package meshes can be instanced, bounds are local until the exact placement/grid mapping, and LOD identity cannot be inferred from a shared meshlet number. Validate part membership in that placement mesh, cluster membership in that part, effective-level membership in that cluster, and meshlet membership in that actual level range with checked arithmetic and no16-bit truncation.

Select LOD with unchanged depth/radius, current quality*far policy, and the existing nonempty helper FIRST. Query only the returned effective level. An empty requested coarse level falls back to the finer authored nonempty level and uses its meshlet tuple/proof; no empty/coarse entry can authorize cutting its replacement. An empty base naturally yields no meshlet query. Missing level/tuple/proof means draw. LOD or package changes invalidate all foreign tuples.

The offline bound for one tuple encloses every authored corner/triangle of that entire selected meshlet under the exact pinned physical affine. Current strip-group selection may draw less, so a whole-meshlet bound remains conservative without changing its strips, winding, UV/material, index encoding or current cloud16+12 world-vertex layout. A proof for one level's let never authorizes another level. All possible effective target LODs need separate descriptors or otherwise draw all; no selected-camera roster is substituted for those cases. Source panels retain the current single-LOD/invariant-geometry admission and actual parity-correct shared-index rules.

## Compose at a safe point

Preserve existing whole-cluster R4PV behavior. A zero whole-cluster bit may skip the cluster only under its unchanged proof contract. A partially hidden cluster keeps its whole-cluster visible bit; a separate per-let relation can then refuse only an exact selected tuple. It cannot synthesize a whole-cluster hidden bit or hide unrelated parts/placements.

For a minimal first integration, force only parts with authenticated per-let candidate metadata onto the existing direct path, drain earlier queued parts in original order, then obtain a FRESH current-set/frame/generation/key/source-receipt decision at the post-selected-affine, post-effective-LOD, pre-draw point. Do not retain an earlier true/false guard across a drain or binding yield. Calling can_cut before pending occluders have actually been emitted is false; queued source presence alone never supplies a receipt. Re-evaluating after the drain permits already accepted earlier panels to matter without changing their order. Any actual-target guard failure draws that meshlet normally.

Keep `can_cut` requirements intact: current valid set, exact certificate, numeric/frame/FPSCR/view/projection/viewport/near/far key, live scene+generation, original source identities/poses/material/depth/header, COMPLETE successful accepted-panel receipts and target placement strictly after max source placement. Exclude proof-source targets and dependency cycles. The typed let lookup adds ownership/LOD/actual-affine admission; it cannot replace any existing condition. Query immediately before geometry work and recheck after any operation that can invalidate the frame/source epoch. First cohort excludes conditional, animated, deformed or part-hierarchy targets.

A future optimized queued path would require root-reviewed replay identity and epoch handling at the actual emit point. Selection-time cuts based on expected future receipts are unsafe. This design does not permit relaxing chunk_ok, adding replay state, or charging presumed saved setup costs. Direct fallback/extra flushes can lose batching; the model must price that loss, query/lookup cost and data residency against actual selected transform/strip work saved.

## Data and receipt admission still required

The existing certificate binds only its complete v1 table bytes/CRC plus source panel metadata. A second meshlet mask or descriptor list must be authenticated too. Do not append unguarded bytes, overload ninst/cluster offsets or accept a foreign bitset under the old table certificate. Root must choose a separately typed version/schema or an explicitly certificate-bound sparse extension after Meter's counts/heap audit. Include exact file extents, membership validation, per-cell target lookup, all input hashes and overflow/cap tests; no allocation or encoding is chosen here.

Use a small room-local proof-target subset with drawall for absent cells/levels/tuples, rather than allocating the full theoretical product by default. Loading/lending/freeing must retain current room-only ownership, generation invalidation and heap4 floor. Meter supplies actual totals and candidate budgets; target census is not a proof of visibility. No new source panel format or source receipt shortcut is needed merely because target granularity changes, but the new relation must be part of the authenticated proof identity before any runtime cut.

Required controls before any future patch: same let in two placement instances; foreign part/cluster/level; empty-level fallback; missing tuple; changed policy/IDs/layout/hash; dynamic selected affine/sentinel; hidden/part-driven target; source not yet emitted, source failed bind/clip/material/partial receipt; stale frame/scene/generation/key; target at/before source prefix; no-cell/out-of-Y/missing sidecar; partial cluster keeps unrelated lets; PVS0/default-off identical selected/transformed words; full direct/queued fallback identity and abort/drain accounting. Actual SH4/selector/raster/near/cull/material proof, >=1ms MODELLED gate, later private pair and physical checks remain separate.

## Proposed next review boundary

Root and Meter first select a small, yield-supported selected-meshlet target cohort and typed namespace budget. Then prove actual candidate source patches against those whole-let bounds over unchanged admissible camera volumes, retaining all LOD/owner and renderer obligations. No finer target proof, source edit, new data option or SDK/guest is performed by this design unit.
