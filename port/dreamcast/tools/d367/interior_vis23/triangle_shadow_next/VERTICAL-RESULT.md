# Fixed-XZ vertical-domain design result

The approved pair and whole all-LOD target box have no admissible nominal vertical interval for any of the existing hut647 2 m, 500 mm or 250 mm XZ domains. This is an exact empty intersection of the sufficient union theorem's halfspaces, not a sampled negative, quantization failure or proof of actual visibility. The previous fixed-eye whole-target positive and every full-height zero receipt remain immutable.

For each XZ domain, 240 strict linear inequalities a*Y+b>0 are derived with exact Fraction arithmetic. They include both source planes and target plane signs, the positive common source/target chart, opposite shared-diagonal sides, strict convexity and every outer edge at all four XZ corners and all eight target corners. Both global orientation choices and both diagonal choices are evaluated independently. Fixed source determinant predicates are affine in E; tensor-product corner interpolation covers the continuous XZ x target product. Exact Y0/Y1 coefficients have additional algebraic evaluation controls, but the determinant identity supplies affinity.

The viable orientation/diagonal branch has no constant refusal. Its outer-edge inequalities require incompatible bounds: at 2 m, Y>229417.8725 mm and Y<-31713.7735 mm; at 500 mm, Y>10236.3517 and Y<-19410.9562; at 250 mm, Y>-354.9221 and Y<-7495.6703. Full exact rational bounds, predicate labels and every coefficient are private evidence. Other branches fail orientation/diagonal signs. No positive-width signed100mm band exists because each real interval is already empty.

The existing R4PV Cell stores signed int16 ylo/yhi in100mm units. The current selector accepts inclusive endpoints, clears cur before selection and returns without a set outside the band; hidden then returns false without cur. Signed16-bit times100 fits below2^24 and has an exact float representation, but actual inverse-view eye recovery, selector preimage and true-eye uncertainty remain unqualified. The generic pvs_emit.py adds1000mm padding on each side and rounds outward, so file-format representability would not imply its unchanged CLI emits the proposed narrow band. No emitter or runtime change is made.

Six public groups pass, including exact rational intersection, empty/constant cases, strict signed quantization, an analytic square bound and nonplanar-pair equivalence with the unchanged continuous exact_union oracle. Three mutants (outer inequality omission, inclusive boundary quantization and inequality direction) fail intended assertions. A trial coefficient mutation was caught by the solver's nonaffinity check before the intended assertion and is retained as an attempt, not counted as a passed semantic mutant.
