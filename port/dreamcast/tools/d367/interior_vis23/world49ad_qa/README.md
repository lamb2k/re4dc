JOBS=1, automatic pruning disabled and release priority. Admission rechecks both
Windows Python and WSL free space after slot acquisition, using the lower value
with a 24 GiB floor. Each programme uses a new object directory. After its full
ELF, raw main, scrambled programme, all 14 overlays, resolved flags, source,
compiler log, actual ELF symbol/section maps and sizes are preserved and hashed,
only that exact owned rebuildable object directory is deleted with a manifest.
No additional linker flags are introduced to obtain the maps.
