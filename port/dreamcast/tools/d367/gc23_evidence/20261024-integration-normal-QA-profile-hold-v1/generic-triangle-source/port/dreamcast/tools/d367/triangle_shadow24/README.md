## API and fixed assignment

`cover_triangle(eye_vertices, source_triangle, target_triangle)` tests one FIXED nondegenerate source triangle against ALL eye-vertex/target-vertex Cartesian products. The eye domain is the convex hull of the supplied vertices, not an authenticated finite camera roster or permission to shrink a domain. `eye_box(low,high)` constructs a closed eye box only. Actual source and target each have exactly three vertices; no target AABB, planar flattening, ray hit, per-vertex source choice or per-eye source choice is substituted.

`cover_assigned(eye_vertices, target_triangles, fixed_sources)` requires a separate complete nonempty target tuple and equally long SourceFace tuple. Each target triangle chooses exactly one whole source face for the ENTIRE eye cell. Every target triangle must pass; no zip truncation, target pruning or partial-coverage union. Different COMPLETE target triangles may choose different source faces. The result lists every assignment and the sorted dependency union, which is an AND requirement, not an OR mask.

A SourceFace refers to one of the two oriented triangles of a FULL Panel object. Both faces are retained/validated, and the same Panel ID cannot have conflicting full geometry, including a different unused face. At most16 distinct full Panel IDs are accepted;32 mathematical faces belonging to16 full Panels are not32 Panels. ## Exact-real sufficient condition

For source A,B,C put n=(B-A)x(C-A), d(P)=n dot(P-A), and fix one sign s from the first nonzero eye distance. Require s*d(E)>0 at EVERY eye vertex and s*d(T)<0 at ALL three target vertices. For every cyclic source edge U,V require s*det(E-U,V-U,T-U)>0 for EVERY eye/target Cartesian pair.

The plane values are affine and H(E,T) is separately affine in E and T. For convex coefficients alpha,beta, H(sum alpha E,sum beta T)=sum alpha_i beta_j H(E_i,T_j). Strict fixed signs thus cover every point of the closed domains, including target edges/vertices. Delta=d(E)-d(T) has sign s, t=d(E)/Delta lies strictly in(0,1), and the source-plane intersection has barycentrics (H_BC,H_CA,H_AB)/Delta. Their sum is1 because the numerators sum to Delta, and all are strictly positive. Source intersection is inside the open source triangle and before target.

Source degeneracy, eye/source-plane contact or mixed eye sides, target plane contact/before-source depth, and edge-volume contact/nonuniform signs refuse. Degenerate TARGET triangles still pass only if all their points satisfy the same conditions; they are retained, never silently pruned. Orientation reversal is handled geometrically, not permission to reverse culling or assume a two-sided source. Returned minimum plane/edge values are UNNORMALIZED exact polynomials, not millimetre/view-depth/raster margins. Infinitesimal strict positives are mathematical only.
