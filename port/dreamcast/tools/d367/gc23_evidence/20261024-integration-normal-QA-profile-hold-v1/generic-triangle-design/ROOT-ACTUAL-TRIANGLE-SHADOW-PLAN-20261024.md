# Actual-target-triangle shadow prerequisite proposal (source/design only)

Root proposal 2026-10-24. Existing whole-cell target bounding-box tests, including the new patch2810 minimal disks, have no nominal positives. Do not repeat smaller domains or relabel sampled hits. This proposal tests a different sufficient condition: actual emitted target triangles rather than empty space in a meshlet AABB. No runtime/schema/table/asset/SDK/guest grant follows.

For each exact physical target tuple (placement, field, part, cluster, effectiveLOD, globallet), recover every actual oriented target triangle from authenticated final mesh/header/policies and strip parity. Preserve all actual geometry and all possible ordinary selected/cut/clip cases; no target pruning or changed winding. A successful whole-let certificate must cover EVERY target triangle and its original vertices. Source triangles are individually actual opaque/static/admitted triangles whose matching prefix emission receipt is required. Across one certificate, dependency panels remain at most16. No curved/noncoplanar connected patch is flattened or declared convex.

Proposed elementary theorem for independent review: fixed nondegenerate source triangle A,B,C; eye E ranges over a convex camera cell, and point T over an actual convex target triangle. Require strict opposite, fixed sides of source plane for all eye cell vertices and all target triangle vertices. Require the three oriented source-edge/toward-T determinant tests to have the source interior sign for every Cartesian product of eye vertex and target vertex. A determinant with two fixed source endpoints and E,T is affine in E separately and T separately. Its convex-combination expansion is a weighted sum over those Cartesian corner products. With a fixed nonzero source orientation for every eye, all required strict signs then hold for every E,T, so segment E--T crosses the source plane inside actual source triangle and strictly before target. This is a proposed exact-real sufficient theorem, not yet approved numeric/raster arithmetic.

One target triangle may choose one different covering source triangle from another. Coverage of every complete target triangle is sufficient for their union; partial triangles covered only by several different shadows are refused in this first unit. This avoids needing a nonconvex union-shadow theorem or falsely treating sampled vertex hits as complete coverage. A dependency-mask union still requires every assigned source receipt before hiding the whole let. This can be more conservative than a valid coplanar disk theorem, but less conservative in target shape than an AABB.

First step: independent exact-real theorem review and bounded synthetic rational controls/counterexamples only. Verify sign conventions, strict depth, eye/source degeneracy, camera convexity, bilinear endpoint theorem and target triangle closure. No assumption that this yields a useful cut. Then propose one bounded actual-data opportunity audit from existing retained data, over unchanged129 cameras/fullY and2m/500/250 domains, with exact source/target geometry and no new rays. Use current eligible source pool/effective0 theorem only after final binding. All meshlet/SG/cull/clip/material/source ordering/numeric emission acceptance remains independently necessary and unknown. Keep current 110000-ray ledger; zero-ray controls do not spend scene queries.

A future numeric certificate would separately have to enclose actual SH4 dequantization/affine/eye/transform/depth/raster uncertainty, actual source panel emission, effective target LOD identity and fresh frame/cell/package/source state. Exact-real signs alone admit no runtime hide. No table format or runtime memory/layout is approved here. Do not invent a speed gain from corners; the existing>=1ms MODELLED room gate and both memory gates still apply before a console pair.
