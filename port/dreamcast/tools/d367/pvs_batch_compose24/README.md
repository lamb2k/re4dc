## Normal frame contract and unsupported fault reentry

The sole sourceWorldTexturePrepare caller is re4dc_ui_begin. Source Render_before calls it before viewport/default filter work; main Render completes Render_done/Render_swap before the next Render_before. Each world ps2_pass drains a stack-local SubmitScope before returning; ordinary direct draws end before their abort path. Cold load closes an idle batch before load/yield/error loops. The extracted complete flush and actual cold boundary test these synchronous retirements.

There are ALSO Render_before calls in dvd.cpp and exception.cpp. A fatal fault DURING active SQ can therefore reenter rendering outside the normal contract. Prepare's memory-only held refusal preserves the current diagnostic/live ticket and calls no manager/log; it is NOT a generic source-admission revocation or a safe new frame. re4dc_ui_begin is void and its caller continues, so an early return there is deliberately NOT presented as a solution. No frame-begin, fatal exception or manager semantics are changed. Fatal/exception reentry needs a separate end-to-end caller abort/quiescence protocol owned by root. This unit proves its added acquisition logging stays outside SQ under supported synchronous ownership; it does NOT claim every baseline fatal log is safe.
