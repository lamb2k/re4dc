# Synchronous ownership and fault-path limit

Source facts are bound in the host receipt by exact file hashes. No game call path executed.

`src/game/main.cpp` invokes Render_before, Render, Render_done and Render_swap in source order. Render_before (`main_sub.cpp`) calls void re4dc_ui_begin, then unconditionally updates GX viewport/cache/filter. Render_done/copy and Render_swap follow. The sole sourceWorldTexturePrepare call is in re4dc_ui_begin after ordinary asset preparation, before source rendering; its include is earlier in the same translation unit.

Normal PS2 world drawing is synchronous through ps2_pass. Its local chunk_flush owns SubmitScope and its destructor closes the idle retained batch before every normal or early-abort return. Each emitted context runs actual end_direct before pvs_finish and before model_packet_abort. A partial source result closes the batch and clears pending without committing. A successful source-pending result closes before the unchanged material eligibility check. A failed begin closes the idle prior prefix; a nested live begin cannot revoke another owner's lock. Cold load closes the idle batch before invoking load (which may yield or enter DVD error handling). Actual extracted lambda/tails/FailedBegin/load-boundary tests assert physical state at commit/load/log/abort and pending UV restoration.

That is not a universal fault proof. dvd.cpp and exception.cpp also call Render_before. A fault during ACTIVE SQ is an existing unsupported reentrant renderer path. Returning early from void ui_begin would not abort its caller, so this unit adds no frame-begin workaround. Prepare's held refusal only avoids this unit's new diagnostic/reset/manager work while preserving the current owner/event; it does not revoke a source ticket or declare the continuing fault render safe. A separate caller-wide abort/quiescence protocol is required if root admits that scenario. No baseline fatal logging safety claim follows from the normal cold-I/O close proof.

The source manager's ticket prepare/retirement path is unmodified. Captured diagnostic frame/key are separate from mutable current preparation globals, and Acquired is never used as a pending-state enum. Both world SQ starts mark actual ownership; ordinary physical end or idle batch close clears it and flushes, and a successful prepare flushes old event before USED/reset/new ticket. Single pending capacity is sufficient for one source preparation ticket on the supported synchronous frame path; unexpected held prepare returns without logging/reset, and an unexpected pending collision does not overwrite old evidence.

Default0 preserves original source/Make behavior and contributes no persistent state. In enabled mode only PVS target authority is suppressed; internal source observations, normal non-PVS culling and material/scene checks remain. Raw receipt counts on originfb254 must not substitute for interior's later selected-original-affine source proof. Root owns that separate merge and full target admission.
