Native collector

WindowsApi is lazy: import performs no WinDLL call; only an explicit future constructor binds native functions. GetFileInformationByHandleEx(FileIdInfo/Basic/Standard) pins source native128ID (and its NTFS inode lower64), size/mtime, allocation/count/type. Every named alias is freshly opened in each snapshot and compared against its retained handle; no samefile Boolean is accepted. GetFinalPathNameByHandleW must equal the canonical C path. Directory handles disallow directory rename; reparse points and lexical aliases are rejected. File handles deny write sharing and permit delete sharing. Qualification retains READ-only access, so it does not require ordinary ISO readers to share DELETE access. Only post-stop cleanup opens the exact current alias with DELETE access, compares it with its retained READ identity, then closes READ before disposition. FindFirstFileNameW/FindNextFileNameW must enumerate the whole exact3/4 image set without truncation/extra/duplicate entries. All names, counts and per-ref identity/stat records must match before and after hashing. Common tracks are exact same native objects/source hashes across declared aliases, without pretending their other shared names are exclusively owned.
